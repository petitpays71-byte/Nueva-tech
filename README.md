Votre plateforme est prête dans le fichier `index.html`.

- **Parcours :** vous créez des parcours (par exemple « Électronique de base »), chacun avec ses leçons.
- **Vidéos :** vous ajoutez une leçon avec un lien YouTube ou un fichier .mp4. Le lecteur reprend là où vous vous étiez arrêté.
- **Progression :** une barre d'avancement par parcours, une coche par leçon, et la leçon se valide toute seule à la fin de la vidéo.

Les données restent dans le navigateur de chaque apprenant, donc il n'y a pas de comptes ni de serveur.

Pour la mettre en ligne depuis votre téléphone :
1. Sur votre dépôt GitHub, appuyez sur « Code », puis ajoutez un fichier et envoyez `index.html`.
2. Dans Paramètres → Pages, choisissez la branche « principal » et enregistrez.
3. Après environ une minute, GitHub vous donne l'adresse du site.
